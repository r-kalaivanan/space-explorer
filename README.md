# space-explorer
A space-themed landing page built as part of The Odin Project foundations curriculum.

This page features :

- A navigation bar
- Hero section
- Information section
- Quote section
- Call-to-action section
- Footer

Built with :

- HTML5
- CSS3
- Flexbox
- Google Fonts (Space Grotesk, Inter)

What I learned :

- Structuring a HTML page using semantic elements.
- Creating layout using CSS flexbox.
- Aligning and spacing elements.
- Using images and working with fonts
